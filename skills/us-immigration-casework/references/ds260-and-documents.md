# DS-260 and private document preparation

Use `assets/ds260-worksheet.json` as a private preparation aide, not an official CEAC form, import format or exhaustive conditional schema. Verify current DOS/NVC/KCC/post instructions for the applicant's actual category before recommending or filling. Distinguish DS-160 temporary-visa preparation from DS-260 immigrant-visa preparation, and distinguish a draft, online submission, documentary qualification and interview. Ask for missing facts rather than inferring answers.

Start with identity, passport, contact/address history, family, travel/immigration history, work/education, petitioner/category, each actual security/background question, SSN choices, preparer and applicant review. The bundled section headings group work; they are not exact current CEAC screens. Add every conditional question actually presented. Never replace individual security answers with a generic all-negative statement or a section-level checkbox. Confirm native-script/name/transliteration fields, dates and prior refusals against originals. Keep unreviewed OCR unverified. Do not request CEAC passwords, invoice IDs or security answers through a public bot.

The worksheet records per-field ID, section, exact label, type, value, requirement, evidence status, document/page references and applicant confirmation. Boolean fields require actual booleans, date fields require YYYY-MM-DD, and N/A requires both live-form permission and a documented basis. `forms.py review` reports selected checks without printing private values. A clean result is only worksheet coverage; it does not establish truth, eligibility or CEAC completeness. The `current_form_question_by_question_reviewed` flag records human attestation, not automatic validation.

Use `forms.py export` for a reviewable draft in Markdown/HTML/JSON and optional PDF/Word via the existing private packet exporter. Values appear in the exported report, so keep it outside Git and review before sharing. Applicant-specific worksheets are not stored in the installed skill or public repository. The applicant reviews the actual current questions and personally signs unless a verified official exception applies. The agent does not certify or submit. After actual submission, preserve the confirmation page and current post instructions; do not claim it was submitted without evidence.

For civil/financial documents, build an applicant-specific checklist based on category, country, reciprocity table and current post instructions. Record authority, format, language/translation requirement, original/copy expectations, date and any expiry. Do not label translations certified unless the appropriate person actually certifies them. A missing document needs a supported explanation and the current official procedure; no fabricated replacement. I-864, I-130, I-485 and specialized forms require their own current instructions, edition and appropriate professional review. “Document preparation” is not universal form compatibility or legal authority.

Template filling:

- `forms.py fill-pdf` supports explicitly selected text AcroForm fields via optional pypdf. It preserves the original, refuses unknown fields, encrypted copies, XFA and signed documents, writes a separate draft, then checks canonical field values. Scan-only PDFs and unsupported controls require a different host workflow. Inspect widgets and rendered appearances against canonical fields before delivery; do not blindly repair ambiguous/orphaned widgets.
- `forms.py fill-docx` supports explicit `{{KEY}}` placeholders in ordinary paragraphs, tables, headers and footers via optional python-docx. Tokens spanning standard text runs are handled; inserted text inherits the first token run's style. Unsupported layouts/unmapped tokens fail where detected. Footnotes, text boxes, tracked changes, complex fields, macros and digital signatures are outside this helper's supported workflow. Use the host's document skill for them; do not promise complete formatting preservation.
- Keep signatures, sworn assertions and official certifications for their actual authors. Do not modify signed originals. Render and visually inspect all pages of actual PDF/Word results, in addition to checking field values/placeholders and source SHA-256.

```bash
python3 "$SKILL_ROOT/scripts/forms.py" review --input /private/case/ds260.json
python3 "$SKILL_ROOT/scripts/forms.py" export --input /private/case/ds260.json --out /private/case/ds260-draft
python3 "$SKILL_ROOT/scripts/forms.py" fill-pdf --template /private/case/form.pdf --mapping /private/case/map.json --out /private/case/pdf-draft
python3 "$SKILL_ROOT/scripts/forms.py" fill-docx --template /private/case/letter.docx --mapping /private/case/map.json --out /private/case/word-draft
```
